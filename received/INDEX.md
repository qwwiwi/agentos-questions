# Received Questions

Папка с входящими вопросами от участников интенсива AgentOS. Каждый вопрос — отдельный файл `YYYY-MM-DD-<username>-<topic>.md`. Оригинальный QUESTION.md сохраняется как есть; шапка с метаданными (от кого, ссылка на источник, дата получения, статус) добавляется в начало файла.

## Статусы

- `new` — получен, ожидает ответа
- `in_review` — принц читает
- `answered` — ответ дан
- `archived` — закрыт
