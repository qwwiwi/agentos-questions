_Дата ответа: 2026-05-29_

Юлия, вопрос подробный — отвечаю по существу.

### Диагноз

Ты проектируешь «ЦИФРУ» сразу как платформу на 10 000 учеников при нуле учеников. Это самая дорогая ошибка соло-фаундера: месяцы уходят в инфраструктуру, которая не нужна, пока нет первой сотни оплат. Твой единственный канал продаж сейчас — медийка, и именно она пока не стоит. Значит первый агент нужен не ученикам, а **тебе** — это контент-фабрика.

Сократи проект до одной работающей петли: **трафик -> Telegram-канал/чат -> продажа первого продукта (~2000 ₽) руками**. Никакой платформы и даже никакого GetCourse на старте. Цель этапа — **первые 100 продаж по ~2000 ₽**, собранные вручную. Только после этого имеет смысл делать флагманский продукт, и уже под флагман — платформу. Всё остальное (платформа, услуги, агентство) докупается этой петлёй, а не предшествует ей.

### Рекомендуемая архитектура (по этапам: от «руками» к автоматизации)

Принцип: **сначала продажи руками, инфраструктура — под доказанный спрос.**

**Старт (до первых ~100 продаж) — без платформы вообще:**

- **Telegram-канал + закрытый чат.** Весь трафик из медийки ведёшь сюда. Первый продукт продаёшь прямо в канале/чате — это и есть твоя «платформа» на старте.
- **Оплата вручную** — ссылка Продамус или перевод, доступ в закрытый чат выдаёшь руками. На сотне продаж ручная выдача реальна и ничего не стоит.
- **Один агент — контент-фабрика для ТЕБЯ.** Единственный агент, нужный на старте: пишет тебе посты/Reels по бренд-гайду, ты редактируешь и публикуешь. Медийка — твой канал продаж, поэтому первый агент усиливает именно её.

**Потом (после ~100 продаж, под флагманский продукт):**

- **GetCourse** как витрина флагмана — уроки + автоматический приём оплат. Свою LMS по-прежнему не пишем.
- **Тонкий Telegram-бот** — лид-магнит -> бесплатные уроки -> оффер -> ссылка на оплату. Бот ловит лид и пишет в базу.
- **Ядро (agent-first) — self-hosted Supabase на российском VPS** (Timeweb/AdminVPS): таблицы `leads`, `students`, `content`, `kb_chunks`. PostgreSQL + pgvector + Auth + авто-REST API из коробки. Агенты ходят в данные через API/MCP, не через интерфейс — это Agent Native.
- **База знаний — pgvector** в той же Supabase: твои выверенные методички, «мозг», из которого агент берёт факты, а не выдумывает.

Почему российский VPS + self-hosted Supabase (когда дойдёшь до этого этапа): данные в РФ (152-ФЗ), оплата картой РФ, без VPN-боли, один сервак закрывает БД + API + Auth + вектор за ~₽150–1300/мес.

### План на 30 дней (MVP этапа 1)

| Неделя | Что собрать |
|---|---|
| 1 | Telegram-канал + закрытый чат. Описание первого продукта (~2000 ₽). Приём оплаты руками (Продамус-ссылка/перевод), ручная выдача доступа. Завести трафик из медийки. |
| 2 | Контент-фабрика. Claude Code + агент по твоему бренд-гайду генерит черновики постов/Reels -> ты редактируешь и публикуешь. Цель — стабильный поток в канал. |
| 3 | Продажи руками. Прогрев в чате, ответы на возражения, доведение до оплаты. Считаешь 5 чисел в одной таблице: трафик, подписки, прогретые, продажи, выручка. |
| 4 | Замкнуть и измерить петлю «пост -> канал -> продажа ~2000 ₽». Зафиксировать конверсию. Цель этапа — выйти на траекторию первых 100 продаж. |

GetCourse, Supabase, бот, платформа — следующий этап, **только под флагманский продукт после первых продаж.** Этапы платформа/услуги/агентство — бэклог.

### Делать сейчас vs отложить

| Делать сейчас (80% ценности) | Отложить (до первых ~100 продаж) |
|---|---|
| Telegram-канал + чат, продажа руками | GetCourse, тонкий бот, Supabase |
| Оплата вручную (Продамус/перевод) | Своя LMS-платформа на 10к |
| ОДИН агент — контент-фабрика для тебя | Агенты, говорящие с учениками напрямую |
| 5 чисел в одной таблице | CRM, сложная сегментация, агентство |

### На чём споткнёшься

- **«Сначала построю инфраструктуру»** — даже GetCourse и бот преждевременны при нуле продаж. Сначала 100 продаж руками в чате, инфраструктура — под доказанный спрос. Триггер на GetCourse/платформу — когда ручная выдача реально перестанет справляться.
- **Флагман до первых продаж** — не строй дорогой большой продукт, пока первые 100 человек не купили простой за ~2000 ₽. Флагман билдишь на их деньгах и их обратной связи.
- **Агенты ученикам напрямую с дня 1** — галлюцинация в обучении бьёт по бренду и по твоей лицензии. Только режим «черновик -> твоё одобрение».
- **База знаний как свалка файлов** (когда дойдёшь до агентов) — источник правды = вычитанные тобой материалы, а не папки как есть.

### Итог

Не строй «ЦИФРУ» и даже не ставь GetCourse на старте. Заведи Telegram-канал и чат, гони туда трафик, продай первый продукт за ~2000 ₽ руками. Сделай 100 таких продаж. Только потом — флагманский продукт, и уже под него — платформу. Один агент-контент-фабрика на старте усиливает медийку — твой единственный канал продаж. Всё остальное докупается продажами, а не предшествует им.
