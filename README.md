# AgentOS Questions

Шаблон вопроса для участников интенсива AgentOS. Чтобы получить ответ от принца — не пиши в чат. Заполни шаблон через своего AI-агента и пришли ссылку.

## Зачем

Принц отвечает только на **подробные** вопросы. Подробный вопрос = ответ за 5 минут. Расплывчатый вопрос = «уточни» и ты ждёшь сутки. Шаблон собран чтобы один раз дать контекст, и не возвращаться.

В чате принц не отвечает. В личке — только если у тебя есть ссылка на заполненный шаблон.

## Как этим пользоваться

Три шага. Полностью agent-native — заполняешь не руками, а через своего AI-агента (Claude Code / Cursor / Codex / ChatGPT с GitHub-доступом).

### 1. Создай свой репозиторий или gist

**Вариант A — public-репо** (рекомендую):
```
gh repo create <твой-юзернейм>/agentos-q-<короткое-имя-вопроса> --public --clone
cd agentos-q-<короткое-имя-вопроса>
curl -L https://raw.githubusercontent.com/qwwiwi/agentos-questions/main/TEMPLATE.md -o QUESTION.md
curl -L https://raw.githubusercontent.com/qwwiwi/agentos-questions/main/CLAUDE.md -o CLAUDE.md
```

**Вариант B — приватная инфа?** Создай GitHub Gist (`gist.github.com/new`), вставь содержимое `TEMPLATE.md`, сделай public-link с anyone-with-link. Этого хватит — gist не индексируется как репо.

### 2. Заполни через агента

Открой папку (или gist в редакторе) в Claude Code / Cursor. Агент прочитает `CLAUDE.md` и поможет заполнить `QUESTION.md` — задаст недостающие вопросы, проверит что нет пробелов, подскажет какие детали нужны.

Не пытайся заполнить руками за 2 минуты. Идея — потратить 15-30 минут с агентом и получить ответ принца за день. Без шаблона ты потратишь те же 15 минут на переписку и получишь ответ через неделю.

### 3. Пришли ссылку

В Telegram **@dashieshiev** ровно одно сообщение:

```
Вопрос по AgentOS: <одно предложение о чём>
<ссылка на твой github.com/.../QUESTION.md или gist>
```

Без вводных «здравствуйте, можно ли». Ссылка + одно предложение — всё.

## Что обязательно в QUESTION.md

Полный список полей — в [TEMPLATE.md](./TEMPLATE.md). Минимум:

- **Кто ты** — роль, опыт, контекст
- **Аудитория** — кому ты делаешь продукт (если речь о продукте)
- **Цифры** — выручка, MAU, чек, размер базы, всё что можешь раскрыть
- **Стек** — язык, фреймворки, БД, hosting, AI-провайдеры
- **Команда** — размер, роли, кто что умеет
- **Бюджет** — на инструменты ($/мес), на разработку, на маркетинг
- **Регион / рынок** — РФ / СНГ / Global / конкретные страны
- **Задача** — что решаешь, какую проблему
- **Что уже пробовал** — экономит время, не предложу одно и то же
- **Ожидаемый результат** — критерий успеха

Есть готовые [examples/](./examples/) — посмотри прежде чем писать свой.

## Что НЕ нужно

- Секреты — не вставляй токены/пароли/private-API-keys в public-репо. Если они часть вопроса — опиши без значения («использую токен X-сервиса»)
- Длинные эссе — структура важнее объёма
- Скриншоты вместо текста — текст агенту/принцу читать проще

## Лицензия / приватность

Этот репозиторий публичный. Твой собственный репозиторий с QUESTION.md — на твоё усмотрение. Если хочешь скрыть детали — gist с unlisted-ссылкой подходит лучше всего.
