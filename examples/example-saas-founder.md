# Вопрос для AgentOS

## 1. Одно предложение

**Мой вопрос:** Стоит ли заменить нашего L1-саппорт-инженера (1 человек, 250 тыс/мес ФОТ) на агента + дашборд для разруливания эскалаций, и если да — какой стек, чтобы не словить регрессии по CSAT?

## 2. Кто я

- Имя / Telegram-юзернейм: Анна, @anna_saas
- Роль: CTO + co-founder
- Опыт с AI-агентами: внедряли GPT-4 в продуктовые фичи (рекомендации), но не во внутренние процессы
- Опыт в кодинге: senior fullstack, 10 лет

## 3. Аудитория и продукт

- **Что за продукт / проект:** B2B-SaaS для агентств недвижимости (CRM + автообзвон через AI)
- **Кому делается:** агентства недвижимости в РФ/Казахстане, 5-50 агентов
- **Что делают без нас:** AmoCRM + ручной обзвон
- **Текущая выручка / MRR:** 4.2 млн руб/мес (ARR ~50 млн руб)
- **Активные пользователи:** 180 платящих компаний, ~2 200 активных пользователей в неделю
- **Конверсия лид → платящий:** 14% (от демо-звонка)
- **Средний чек:** ~23 000 руб/мес на компанию
- **CAC и LTV:** CAC 78 000 руб, LTV 540 000 руб, payback 4 месяца
- **Источники трафика:** холодные исходящие (60%), партнёры (30%), органика (10%)

## 4. Стек

- **Языки:** TypeScript (frontend + backend), Python (ML/AI слой)
- **Фреймворки:** Next.js 14, NestJS, FastAPI для AI-сервисов
- **Базы данных:** Postgres (Supabase managed), Redis для кэша/очередей
- **Хостинг:** AWS (eu-central-1), Vercel для landing
- **AI / LLM провайдеры:** OpenAI (gpt-4o для сложного), Claude Haiku (для дешёвых задач), ElevenLabs (TTS)
- **AI-агенты в работе:** один продакшен-агент (recommender) + Cursor у инженеров
- **MCP-серверы:** не подключали
- **Интеграции:** Telegram Bot (для уведомлений клиентов), Twilio, Bitrix24 API, SendGrid
- **Аналитика:** PostHog (продуктовая), Metabase (бизнес), Sentry (ошибки)

## 5. Команда

- **Размер:** 11 человек
- **Роли:** 2 фаундера, 4 разраба (3 fullstack + 1 ML), 1 дизайнер, 1 саппорт L1, 2 продажника, 1 HR/офис
- **Кто пишет код:** инженеры; фаундеры по 30% времени
- **Бюджет на ФОТ в месяц:** ~2.8 млн руб

## 6. Бюджет

- **На AI-инструменты $/мес:** сейчас тратим ~$1 200 (OpenAI + ElevenLabs), готовы поднять до $3 000 если ROI положительный
- **На разработку $/мес:** в рамках текущего ФОТ
- **На маркетинг $/мес:** 800 000 руб
- **Потолок:** если AI-агент потребует >$5 000/мес — пересматриваем, дешевле оставить человека

## 7. Регион / рынок

- **Страна, где работаешь:** РФ + Казахстан (фокус), Узбекистан (эксперимент)
- **Юрисдикция:** ООО в РФ
- **Платёжки:** ЮKassa, СБП-B2B, для KZ — Kaspi Pay
- **Ограничения:** OpenAI прямой биллинг недоступен, идём через VPN-прокси с европейской картой; Sentry — то же

## 8. Задача

- **Что хочу решить:** L1-саппорт обрабатывает ~70 тикетов/день, из них 80% — типовые («как настроить webhook», «не приходит звонок», «как добавить агента в команду»). Хочу чтобы агент закрывал эти 80% самостоятельно, а L1 разруливал только эскалации и пограничные случаи. Текущий L1 готов перейти на роль L2-инженера (зарплату не урезаем).
- **Зачем сейчас:** в ноябре запускаем enterprise-тариф для агентств 50+, ожидаем кратный рост тикетов; нанимать второго L1 дороже чем оплатить агента
- **Если не решить:** придётся нанимать ещё одного саппорта (+250 тыс/мес) или резать SLA

## 9. Что уже пробовал

- **Пробовал:** запустили simple-chatbot с RAG поверх Notion-документации; работает на FAQ-уровне (10-15% тикетов закрывает)
- **Почему не сработало шире:** не имеет доступа к данным клиента (не может посмотреть «почему не пришёл звонок этому конкретному пользователю»); галлюцинирует на сложных кейсах
- **Где остановились:** хочется агент с tool-calling к нашему API (читать логи, статус интеграций), но боюсь дать LLM доступ к продакшен-данным без чёткого RBAC

## 10. Ожидаемый результат

- **Критерий «получилось»:** 60%+ тикетов закрывается агентом без эскалации; CSAT не падает (сейчас 4.6/5), p95-время-ответа улучшается с 2ч до 5 мин
- **Идеальный сценарий через 30 дней:** L1-инженер переведён на L2-роль, агент стабилен, дашборд показывает классификацию тикетов и причины эскалаций
- **Дедлайн:** 1 декабря — запуск enterprise; до этого хочется хотя бы MVP в проде на 2 недели
